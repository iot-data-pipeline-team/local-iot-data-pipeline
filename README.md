# Real-Time IoT Data Pipeline

## Overview

This project simulates an industrial IoT environment where machine sensor data is generated in real time, streamed through Apache Kafka, processed using Apache Spark Structured Streaming, enriched with business logic, aggregated into business KPIs, and stored in PostgreSQL for analytics and visualization.

The pipeline follows a Medallion Architecture (Bronze, Silver, Gold) commonly used in modern data engineering systems.

---

# Architecture

```text
IoT Machines
      │
      ▼
Kafka Producer
      │
      ▼
Apache Kafka Cluster
      │
      ▼
Spark Structured Streaming
      │
      ├── Bronze Layer (Raw Events)
      │
      ├── Silver Layer (Enhanced Events)
      │
      └── Gold Layer
             ├── Machine Summary
             ├── Hourly Summary
             └── Shift Summary
      │
      ▼
PostgreSQL
```

# Medallion Architecture

## Bronze Layer

### Table

```text
iot_events
```

### Purpose

Stores raw machine events consumed from Kafka.

### Example Columns

- event_id
- event_time
- machine_id
- machine_type
- temperature
- vibration
- rpm
- power_kw

---

## Silver Layer

### Table

```text
iot_events_enhanced
```

### Purpose

Stores transformed and enriched events generated by Spark transformations.

### Transformations

#### Temperature Status

```text
Critical : temperature > 90
Warning  : temperature > 80
Normal   : otherwise
```

#### Vibration Status

```text
Critical : vibration > 5
Warning  : vibration > 3
Normal   : otherwise
```

#### Fault Flag

```text
True  -> 1
False -> 0
```

#### Event Date

Extracted from timestamp.

#### Event Hour

Extracted from timestamp.

#### Health Score

```text
100 - (temperature * 0.3) - (vibration * 5)
```

If machine is in fault state:

```text
health_score = 0
```

The Gold Layer contains business-ready KPI aggregations generated using Spark Structured Streaming.

#### Table


#### Aggregation Level

- Average Power Consumption

- Average Health Score

### Hourly Summary

#### Table

```text
hourly_summary
```

#### Aggregation Level

#### Metrics

- Total Events
- Average Temperature
- Average Vibration
- Average RPM
- Average Power Consumption
