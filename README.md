# Real-Time IoT Data Pipeline

## Overview

This project simulates an industrial IoT environment where machine sensor data is generated in real time, streamed through Apache Kafka, processed using Apache Spark Structured Streaming, enriched with business logic, aggregated into KPIs, and stored in PostgreSQL for analytics and visualization.

The pipeline follows a modern Medallion Architecture (Bronze, Silver, Gold) commonly used in data engineering projects.

---

## Architecture

```text
IoT Machines
      │
      ▼
Kafka Producer
      │
      ▼
Apache Kafka Cluster
      │
      ▼
Spark Structured Streaming
      │
      ├── Bronze Layer (Raw Events)
      │
      ├── Silver Layer (Enhanced Events)
      │
      └── Gold Layer (Aggregated KPIs)
      │
      ▼
PostgreSQL

```

## IoT Data Generator

The producer simulates four industrial machines:

| Machine ID | Machine Type |
|------------|------------|
| CNC_01 | CNC Machine |
| ROB_01 | Robot Arm |
| CNV_01 | Conveyor Belt |
| PMP_01 | Pump |

Each machine continuously sends sensor readings to Kafka in round-robin fashion.

### Simulated Metrics

Common metrics:

- Temperature
- Vibration
- RPM
- Power Consumption

Machine-specific metrics:

#### CNC Machine

- Oil Level
- Coolant Pressure

#### Robot Arm

- Joint Torque
- End Effector Force

#### Conveyor Belt

- Belt Tension
- Load Weight

#### Pump

- Oil Level

# Medallion Architecture

## Bronze Layer

### Table

```text
iot_events
```

### Purpose

Stores raw machine events received from Kafka.

### Example Columns

- event_id
- event_time
- machine_id
- machine_type
- temperature
- vibration
- rpm
- power_kw

---

## Silver Layer

### Table

```text
iot_enhanced_events
```

### Purpose

Stores enriched events generated by Spark transformations.

### Transformations

#### Temperature Status

```text
Critical : temperature > 90
Warning  : temperature > 80
Normal   : otherwise
```

#### Vibration Status

```text
Critical : vibration > 5
Warning  : vibration > 3
Normal   : otherwise
```

#### Fault Flag

```text
True  → 1
False → 0
```

#### Event Date

Extracted from timestamp.

#### Event Hour

Extracted from timestamp.

#### Health Score

```text
100 - (temperature × 0.3) - (vibration × 5)
```

If machine is in fault state:

```text
health_score = 0
```

## Bronze Layer Table

Stores raw IoT events consumed from Kafka.

```sql
CREATE TABLE IF NOT EXISTS iot_events (
    event_id VARCHAR(100) PRIMARY KEY,
    event_time TIMESTAMP,

    machine_id VARCHAR(50),
    machine_type VARCHAR(50),

    floor VARCHAR(10),
    shift VARCHAR(20),

    status VARCHAR(20),
    error_code VARCHAR(20),

    is_fault BOOLEAN,

    temperature DOUBLE PRECISION,
    vibration DOUBLE PRECISION,
    rpm DOUBLE PRECISION,
    power_kw DOUBLE PRECISION,

    cnc_oil DOUBLE PRECISION,
    coolant_pressure DOUBLE PRECISION,

    joint_torque DOUBLE PRECISION,
    force DOUBLE PRECISION,

    belt_tension DOUBLE PRECISION,
    load_weight DOUBLE PRECISION,

    flow_rate DOUBLE PRECISION,
    inlet_pressure DOUBLE PRECISION
);
```

---

## Silver Layer Table

Stores transformed and enriched IoT events.

```sql
CREATE TABLE IF NOT EXISTS iot_events_enhanced (
    event_id VARCHAR(100) PRIMARY KEY,
    event_time TIMESTAMP,

    machine_id VARCHAR(50),
    machine_type VARCHAR(50),

    floor VARCHAR(10),
    shift VARCHAR(20),

    status VARCHAR(20),
    error_code VARCHAR(20),

    is_fault BOOLEAN,

    temperature DOUBLE PRECISION,
    vibration DOUBLE PRECISION,
    rpm DOUBLE PRECISION,
    power_kw DOUBLE PRECISION,

    cnc_oil DOUBLE PRECISION,
    coolant_pressure DOUBLE PRECISION,

    joint_torque DOUBLE PRECISION,
    force DOUBLE PRECISION,

    belt_tension DOUBLE PRECISION,
    load_weight DOUBLE PRECISION,

    flow_rate DOUBLE PRECISION,
    inlet_pressure DOUBLE PRECISION,

    temperature_status VARCHAR(20),
    vibration_status VARCHAR(20),

    fault_flag INTEGER,

    event_date DATE,
    event_hour INTEGER,

    health_score DOUBLE PRECISION
);
```

---

## Gold Layer Table

Stores machine-level aggregated metrics generated by Spark Structured Streaming.

```sql
CREATE TABLE IF NOT EXISTS machine_summary (
    machine_id VARCHAR(50) PRIMARY KEY,

    avg_temp DOUBLE PRECISION,
    avg_vibration DOUBLE PRECISION,
    avg_rpm DOUBLE PRECISION,
    avg_power DOUBLE PRECISION,

    avg_health_score DOUBLE PRECISION,

    fault_count BIGINT,

    fault_percentage DOUBLE PRECISION
);
```
